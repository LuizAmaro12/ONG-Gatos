# Patinhas do Bem
Projeto front-end acadêmico para uma ONG fictícia de resgate, proteção e adoção responsável de gatos.

## Recursos
HTML semântico, CSS responsivo, SPA por hash, templates dinâmicos, validação HTML5 + JS, localStorage, dark mode, acessibilidade, SweetAlert2 e imagens WebP.

## Executar
```bash
npm install
npm run dev
```

## Produção
```bash
npm run build
npm run preview
```
A build é gerada em `dist/` pelo Vite.

## Estrutura
- `html/`: páginas de entrada
- `css/`: estilos e responsividade
- `js/`: módulos JavaScript
- `imagens/`: recursos estáticos otimizados

Versão: 1.0.0
